# Changelog

## 0.1.7

- Add synchronized GitHub/Zenodo software citation metadata, the scientific
  description, confirmed author affiliations, and Gabriel Silva Santos's ORCID.
- Adopt Apache License 2.0 for the project with rights-holder authorization
  confirmed by the maintainer; preserve separate terms for external components,
  model weights, datasets, and institutional marks.
- Document inference/training dependencies, model identities and integrity
  checks, external license restrictions, and remaining archival requirements.
- Inventory development diagnostics and study-specific evidence for archival
  review; preserve all existing images, icons and visual assets.
- Synchronize application manifests at version 0.1.7. Public download fallback
  links continue to use the previously verified 0.1.6 installers until new
  installers are published and verified.

This source release is separate from neural checkpoints, experimental datasets
and installers. It does not introduce scientific validation or a newly
trained rearing classifier. The
annotation/training infrastructure and experimental protocol limitations are
described in the scientific metadata and technical documentation.

The source archive's proposed file selection is recorded in
[the source review](docs/releases/v0.1.7-source-review.md); any archive-only
omissions preserve the files in the repository and require maintainer approval.

The earlier release notes available in this repository are preserved in
[docs/releases/v0.1.5.md](docs/releases/v0.1.5.md). A complete historical changelog
has not been reconstructed.
