# Behavior Tracker 0.1.7 source archive review

This is the proposed content for a source-only GitHub/Zenodo release. Publication
requires the maintainer's approval of this concrete file selection. No experimental
data redistribution permission, model license, DOI or publication date is inferred.

## Preserved content

All application code, build/test configuration, license and metadata, model/data/asset
cards, dependency documentation, synthetic fixtures, all original public/ artwork
and audiovisual files, all desktop icons and software/synthetic UI illustrations
remain included. No original image/icon is deleted or replaced in the repository.

The candidate omits only the files listed below from the generated source archive.
They remain in the repository and Git history. This is not a privacy remediation of
already public history. Files marked mixed include synthetic checks alongside
real-video results; the synthetic checks are not being reclassified as experimental
validation. The exact proposed paths and original hashes are recorded in
[the archive plan](v0.1.7-archive-plan.json).

## Local research files and Git tracking

Use the ignored root directories `private/`, `datasets/`, `training-runs/` and
`checkpoints/` for new personal research inputs and outputs. Neural checkpoint
extensions are also ignored. Keep reusable training code, sanitized configurations,
dependency specifications and synthetic examples public for reproducibility.
Ignoring files is not access control or a backup mechanism.

The 62 study files listed below are already tracked. Adding ignore rules alone
does not make them private or remove them from future snapshots. After approval of
the exact selection, they can be removed from Git's index and added to `.gitignore`
while keeping the local copies. No such index change has been made in this review.
Previous public commits and releases retain their copies; this proposal does not
rewrite Git history. Archive-only omissions below also leave the Git tree public.

## Proposed model-distribution suspension

Keep the OpenCV application independent and preserve verified researcher-provided
bundles and official-source model acquisition under the applicable terms. Do not
attach Wistar checkpoints to the new release or copy them into the source archive.
For the already public distribution, review taking the two assets in
models-wistar-df-v2-r1 offline and the historical installers that contain them
(confirmed for Linux 0.1.4). This would be a separate, explicit maintainer action;
it has not been executed. Hiding only the model release would not remove the copies
inside older installers. See MODEL_CARD.md and the historical distribution audit.

A future provider manifest can separate official-source downloads, immutable hashes,
upstream license terms and user-trained bundles. The current code and tracking
algorithms are preserved; this proposal does not pretend that automatic legacy
Wistar acquisition has already been disabled.

## Current verification

The complete `npm run verify` was executed on the reviewed worktree on
2026-11-27, using synthetic Google client values for the build contracts. Tools
(46), Vitest (274), Chromium/WebKit (128), OAuth contracts (14), Python protocols
(370 run with one platform skip), Python scripts (16), TypeScript, Vite and model
delivery integrity checks passed. The initial command exited unsuccessfully:
Rust reported 113 passes and one failure in
`oauth::tests::browser_success_waits_for_the_app_to_complete_authentication`
while reading its local callback. The complete unchanged Rust suite was then
repeated with the same fixture client values: all 114 tests passed. The failure
did not recur in that rerun; its cause is not established, and the first gate
failure is not being reclassified as a successful command. No authentication or
tracking code was changed to obtain the result.

Metadata passes the CFF 1.2.0 and Zenodo core schema checks, with the Zenodo
version/language fields checked separately from the legacy schema. All eight
application/citation version fields agree at 0.1.7. No DOI, release date or grant
was added. The exact Apache text is retained. No code/test reference to the 62
proposed study-file omissions was found. All original `public/` and desktop icon
files match the base commit; UI screenshots regenerated by the tests were
returned to their original bytes. These checks do not establish installed-app
OAuth, model performance, Colab/GPU operation or independent scientific validity.
