# Behavior Tracker 0.1.7 source archive review

This records the content selected for a source-only GitHub/Zenodo release. The
maintainer approved keeping the 62 identified study files local, removing them
from Git tracking, and committing/pushing this separation. Publishing v0.1.7 is
still not authorized. No experimental-data redistribution permission, model
license, DOI or publication date is inferred.

## Preserved content

All application code, build/test configuration, license and metadata, model/data/asset
cards, dependency documentation, synthetic fixtures, all original public/ artwork
and audiovisual files, all desktop icons and software/synthetic UI illustrations
remain included. No application image/icon is deleted or replaced. The local
copies of the 62 study files also remain unchanged.

The files listed below are individually ignored and no longer tracked. They are
absent from new Git trees and source archives, while their local copies and old
Git history remain. This does not remove already public historical copies. Files
marked mixed include synthetic checks alongside real-video results; the synthetic
checks are not being reclassified as experimental validation. The exact selected
paths and original hashes are recorded in
[the archive plan](v0.1.7-archive-plan.json).

## Local research files and Git tracking

Use the ignored root directories `private/`, `datasets/`, `training-runs/` and
`checkpoints/` for new personal research inputs and outputs. Neural checkpoint
extensions are also ignored. Keep reusable training code, sanitized configurations,
dependency specifications and synthetic examples public for reproducibility.
Ignoring files is not access control or a backup mechanism.

The 62 files were removed from Git's index with `git rm --cached`, preserving their
local copies. Each has an exact, root-anchored `.gitignore` rule; neither directory
is ignored wholesale. Size and SHA-256 are checked against the approved inventory
before and after untracking. The selection remains identifiable by the original
`proposedArchiveAction: omit_pending_data_permission` marker; its approved current
action is recorded separately in the JSON. Previous public commits and releases
retain their copies. No history rewrite or historical-release removal is performed.

## Proposed model-distribution suspension

Keep the OpenCV application independent and preserve verified researcher-provided
bundles and official-source model acquisition under the applicable terms. Do not
attach Wistar checkpoints to the new release or copy them into the source archive.
For the already public distribution, review taking the two assets in
models-wistar-df-v2-r1 offline and the historical installers that contain them
(confirmed for Linux 0.1.4). This would be a separate, explicit maintainer action;
it has not been executed. Hiding only the model release would not remove the copies
inside older installers. See MODEL_CARD.md and the historical distribution audit.

A future provider manifest can separate official-source downloads, immutable hashes,
upstream license terms and user-trained bundles. The current code and tracking
algorithms are preserved; this proposal does not pretend that automatic legacy
Wistar acquisition has already been disabled.
